# Лабораторна робота №4: Інтеграція фронтенду з бекендом

## Інструкція із запуску
1. **Бекенд:** Перейдіть у папку `lab2_backend`, виконайте `npm run dev` (запуститься на порту 3000).
2. **Фронтенд:** Перейдіть у папку `lab4_frontend`, виконайте `npm run dev` (запуститься на порту 5173).

## Сценарії перевірки
- **Успішний POST/GET та CORS:** Заповнити форму (у поле "Репортер" ввести числове ID), натиснути "Додати". Запис з'явиться в таблиці. У DevTools (вкладка Network) видно успішний запит (200/201) та OPTIONS (preflight).
- **Обробка помилки (400):** Ввести текст замість числа в поле "Репортер", відправити форму. З'явиться червоне повідомлення про помилку валідації від бекенду.
- **Стани завантаження:** Оновити сторінку, або очистити БД — відображатимуться стани "Завантаження..." або "Поки що немає записів".

## Правила сумісності DTO (Контракти)
1. Заборонено видаляти або перейменовувати існуючі поля, які вже очікує фронтенд.
2. Нові поля додаються лише як необов'язкові (optional) або з дефолтними значеннями.
3. Зміна типів полів (наприклад, з string на number) або видалення полів допускається лише при створенні нової версії API (наприклад, `/api/v2/`).
